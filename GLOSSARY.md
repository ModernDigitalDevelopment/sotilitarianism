# Sotilitarianism Glossary

A comprehensive reference of all terminology used in the Sotilitarian framework.

---

## Core Philosophy

| Term | Definition |
|------|------------|
| **Sotilitarianism** | A comprehensive socioeconomic philosophy and technical framework proposing a new economic operating system based on verified utility, radical transparency, and decentralized trust. Created by Cornelius Lawrence. |
| **Sotility** | The principle of social utility — the idea that economic value should be measured by its verified benefit to society, not by extraction or accumulation. Derived from "social utility." |
| **Sotilitarian Capitalism** | The economic system proposed by Sotilitarianism. Also referred to as Capitalism 2.0, Social Capitalism, Utilitarian Capitalism, or Transparent Economics. |
| **Capitalism 2.0** | Popular name for the Sotilitarian economic model, emphasizing its role as a successor to extractive capitalism. |
| **Social Capitalism** | Alternative name for Sotilitarian Capitalism, emphasizing the social-utility foundation of the system. |
| **Utilitarian Capitalism** | Alternative name emphasizing the utilitarian philosophical roots — the greatest good for the greatest number, verified on-chain. |
| **Transparent Economics** | The economic paradigm of on-chain, publicly verifiable financial systems where opacity is structurally impossible. |

## Technology Terms

| Term | Definition |
|------|------------|
| **Trust Tech** | Technology infrastructure for building trustless, transparent systems. The technical foundation of Sotilitarianism. |
| **Transparency Tech** | Technology that makes institutional operations publicly verifiable, eliminating information asymmetry. |
| **Trust Kernel Stack** | The foundational trust infrastructure layer that underpins all Sotilitarian systems. |
| **Five-Layer Architecture** | The technical structure of the Sotilitarian system: Token Layer, Social Layer, Financial Layer, Governance Layer, and AI & Verification Layer. |
| **Proof of Utility** | A consensus mechanism based on demonstrated social benefit rather than computational work or stake. |

## Token Economy

| Term | Definition |
|------|------------|
| **SOT (Sotility Ownership Token)** | The governance token of the Sotilitarian ecosystem. Used for voting on proposals, electing stewards, and shaping the Foundation's direction. |
| **SUG (SoGood Utility Governance Token)** | The utility token for accessing platform features, paying for services, and earning through participation. |
| **SST (Sotility Stable Token)** | A USD-pegged stablecoin for everyday transactions and treasury reserves. Provides economic stability within the ecosystem. |
| **Three-Token Economy** | The integrated economic model using SOT, SUG, and SST, each serving a distinct purpose while forming a unified ecosystem. |
| **Token Distribution Architecture** | The framework governing how SOT, SUG, and SST are minted, distributed, and circulated within the ecosystem. |

## Economic Models

| Term | Definition |
|------|------------|
| **Dual-Lever Economic Model** | The Sotilitarian economic framework that simultaneously addresses demand-side (participatory income) and supply-side (transparency efficiency) economics. |
| **UMFL (Utility Maximization Feedback Loop)** | A self-reinforcing cycle where increased participation drives efficiency, which drives value, which drives further participation. |
| **Trojan Horse Effect** | The phenomenon by which transparent systems naturally displace opaque competitors through superior efficiency and trust. |
| **Participatory Income Engines** | Mechanisms that create broad-based income through tokenized rebates (SST), contribution rewards (SUG), and ownership distributions (SOT). |
| **Transparency Efficiency Drivers** | Mechanisms that drive market-wide efficiency through on-chain accountability, smart contract automation, and AI verification. |

## Governance

| Term | Definition |
|------|------------|
| **Continuous Consent** | Ongoing democratic participation replacing periodic elections. Citizens can vote, delegate, and recall at any time. |
| **Liquid Democracy** | A governance model where token holders can vote directly or delegate their votes to trusted representatives, with real-time recall capability. |
| **R-Score (Reputation Score)** | An on-chain metric measuring verified contributions to the ecosystem. Influences governance weight and platform access. |
| **Multi-Level Governance** | The Sotilitarian governance architecture spanning individual sovereignty, community governance, regional coordination, and global protocol layers. |
| **Sotilitarian Governance** | The complete governance framework based on continuous participation, verified transparency, and tokenized decision-making. |
