| Application | Funder | Amount | Status |

## How to Submit

### Ethereum Foundation ESP
1. Visit [esp.ethereum.foundation](https://esp.ethereum.foundation)
2. Click "Apply" → "Project Grant"
3. Use the content from [ethereum-foundation-esp.md](ethereum-foundation-esp.md) to fill out the form
4. Attach the [Sotility Pitch Deck](../pitch-deck/sotility-pitch-deck.pdf)

### Gitcoin Grants
1. Visit [explorer.gitcoin.co](https://explorer.gitcoin.co)
2. Create a project profile for "Sotility Protocol"
3. Use the content from [gitcoin-desci-round.md](gitcoin-desci-round.md) for the project description
4. Apply to the DeSci round during the next grant cycle
