## What Is Sotilitarianism?

**Sotilitarianism** (also known as *Sotilitarian Capitalism*, *Social Capitalism*, *Utilitarian Capitalism*, or *Capitalism 2.0*) is a comprehensive socioeconomic philosophy and technical framework that proposes replacing extractive capitalism with an economic system governed by **verified social utility**.

The word **"Sotility"** derives from a synthesis of *social utility* — the principle that economic value should be measured by its demonstrated benefit to society, not by extraction, speculation, or accumulation.

> "The system was not built for us. So we are building our own."

Sotilitarianism is not a reform of existing systems. It is a **protocol-level replacement** — a new economic operating system that makes financial transparency the default, community governance the standard, and economic empowerment the outcome.

## Core Principles

| Principle | Description |
|-----------|-------------|
| **Radical Transparency** | Every financial transaction, governance vote, and operational decision is recorded on-chain and publicly verifiable. No exceptions. |
| **Community Sovereignty** | Token holders govern the system through continuous participation. No single person, board, or entity controls direction. |
| **Autonomous Finance** | Smart contracts execute without human intermediaries. The Elevation Engine generates yield autonomously. |
| **Verified Utility** | Value is measured by demonstrated social benefit through on-chain proof, not by speculation or extraction. |
| **Participatory Economics** | All participants earn, govern, and benefit proportionally through tokenized incentive alignment. |

## The Three-Token Economy

Sotilitarianism operates on a three-token economic model, each serving a distinct purpose:

| Token | Name | Purpose |
|-------|------|---------|
| **SOT** | Sotility Ownership Token | Governance — vote on proposals, elect stewards, shape direction |
| **SUG** | SoGood Utility Governance Token | Utility — access platform features, earn through participation |
| **SST** | Sotility Stable Token | Stability — USD-pegged for everyday transactions and treasury reserves |

Together, these three tokens form a self-sustaining governance and financial ecosystem.

## The Dual-Lever Economic Model

Sotilitarianism transcends the traditional demand-side vs. supply-side dichotomy by simultaneously addressing both:

**Demand Side** — Participatory income engines via tokenized rebates (SST), contribution rewards (SUG), and ownership distributions (SOT)

**Supply Side** — Transparency efficiency drivers via on-chain accountability, smart contract automation, and AI verification

This creates the **Utility Maximization Feedback Loop (UMFL)** — a self-reinforcing cycle where increased participation drives efficiency, which drives value, which drives further participation.
