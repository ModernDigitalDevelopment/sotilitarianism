## Total Scope

The complete book spans approximately **117,000 words** across five documents, making it a comprehensive treatise comparable in scope to major works of economic and political philosophy.

## Key Themes by Part

**Part I** establishes *why* — the systemic failures of extractive capitalism, the erosion of democratic agency, and the philosophical case for a new economic operating system.

**Part II** establishes *what* — the specific economic mechanisms, token models, and financial architecture that make Sotilitarianism function as a self-sustaining system.

**Part III** establishes *who governs* — the political structures, voting mechanisms, and accountability frameworks that ensure the system remains democratic and resistant to capture.

**Part IV** establishes *how* — the technical implementation, smart contract architecture, security model, and deployment strategy.

**The Expanded Edition** synthesizes and updates the core ideas with the latest developments in the Trust Kernel Stack and Proof of Utility consensus mechanism.
